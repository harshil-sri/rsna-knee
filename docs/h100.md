# H100 Supercomputer Runbook

## Etiquette & Quota
- Usable daytime only.
- Remote storage quota: 100GB hard cap.
- Always delete data and virtual environment after each session to stay within quota.
- Keep checkpoints minimal: sync only `best.pt` and `last.pt`.

## Storage Plan
- Remote subset: ~55GB local subset in `/mnt/ssd/rsna-knee/data/`.
- Bootstrap checks that local data is <90GB before transferring to prevent disk overflow.

## Command Sequence
1. Set host configuration:
   `export H100_HOST=user@hostname` (or write to `~/h100.host`)
2. Bootstrap environment and sync subset data:
   `bash tools/h100/bootstrap.sh`
3. Launch training:
   `bash tools/h100/launch_train.sh --fold 0`
4. Or launch inference:
   `bash tools/h100/launch_infer.sh --ckpt checkpoints/best.pt --out runs/preds.csv`
5. Pull results:
   `bash tools/h100/pull_results.sh`
6. Clean remote storage post-session:
   `ssh $H100_HOST "rm -rf ~/rsna-knee/data ~/rsna-knee/.venv"`

## Resume from Checkpoint
- `src/train.py` saves `checkpoints/last.pt` every epoch.
- To resume training on H100:
  `bash tools/h100/launch_train.sh --fold 0 --resume checkpoints/last.pt`
